La recherche et l’actualisation sont automatiques. « Vérifier tous les flux » relance la recherche. Les flux vides, invalides ou bloqués ne sont pas affichés dans la liste.
API à clé et budgets de requêtes

TBM Bordeaux, Azalys Blois et Sankéo Perpignan sont intégrés avec leurs clés publiques. Les API personnelles ci-dessous ajoutent les prochains passages aux arrêts (points violets à partir du zoom 10). Clique sur un arrêt pour consulter ses horaires.

Les horaires de l’arrêt ouvert s’actualisent automatiquement. Le budget inclut les erreurs et les clics manuels. Les compteurs concernent ce navigateur ; une clé utilisée ailleurs partage le quota de l’opérateur. Une clé dans une page publiée reste accessible aux visiteurs.

Pysae, le GTFS-RT Tisséo et les relais proxy ne sont pas intégrés. Aucun proxy n’est utilisé pour les flux temps réel ; un appel direct bloqué est retiré de l’actualisation automatique.
